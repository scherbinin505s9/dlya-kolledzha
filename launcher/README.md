# Учебный лаунчер

Небольшое окно на Python, которое показывает работы из репозитория и помогает
их сдавать.

## Что умеет

- показывает работы из «Готово к отправлению» и «Отправленные задания»;
- открывает папку работы и её `README.md`;
- собирает ZIP для Moodle: все файлы, кроме `README.md` и старых архивов;
- открывает задание в Moodle по ссылке из `links.json`.

## Запуск

Нужен Python 3 с tkinter (идёт в установщике с
[python.org](https://www.python.org/)).

```bash
cd dlya-kolledzha
py launcher/launcher.py
```

## Ссылки на задания

`links.json` связывает работу и адрес задания на портале:

```json
{
  "ПиРИП/Название работы": "https://portal.edu.asu.ru/mod/assign/view.php?id=..."
}
```

Ключ — папка предмета и папка работы через `/`. Если ссылки нет, кнопка
«Открыть в Moodle» неактивна.

## Как добавить работу

Настраивать ничего не нужно. Лаунчер читает папки при запуске и по кнопке
«Обновить». Новая папка в «Готово к отправлению» или «Отправленные задания»
появляется в списке сама.
