# Учебный лаунчер

Небольшое окно на Python, которое показывает работы из репозитория и помогает
их сдавать.

## Что умеет

- показывает работы из «Готово к отправлению» и «Отправленные задания»;
- берёт статус, дату и имя архива из карточки работы;
- открывает папку работы и её `README.md`;
- собирает ZIP по `files.txt`;
- открывает задание в Moodle по ссылке из `docs/assignments.json`;
- показывает срок сдачи из реестра;
- создаёт заготовку новой работы по шаблону;
- открывает папку работы и задание в Moodle одной кнопкой.

## Запуск

Нужен Python 3 с tkinter (идёт в установщике с
[python.org](https://www.python.org/)).

```bash
cd dlya-kolledzha
py launcher/launcher.py
```

## Реестр заданий

`docs/assignments.json` хранит ссылки и сроки:

```json
{
  "ПиРИП": {
    "course": "https://portal.edu.asu.ru/course/view.php?id=8709",
    "section": "https://portal.edu.asu.ru/course/section.php?id=103535",
    "works": [
      {
        "name": "Название работы",
        "url": "https://portal.edu.asu.ru/mod/assign/view.php?id=...",
        "deadline": ""
      }
    ]
  }
}
```

Название работы должно совпадать с папкой в разделе. Срок — в формате
`ДД.ММ.ГГГГ`, если он известен.

## Состав архива

`files.txt` в папке работы: по одному пути на строку, папки — со слешем.

```
text.htm
mystyle.css
CSS/
```

Если файла нет, лаунчер спросит и соберёт всё, кроме `README.md` и старых
архивов. Имя архива берётся из поля «Архив» в карточке работы.

## Новая работа

Кнопка «Новая работа» создаёт папку в «Готово к отправлению»:

- `README.md` по шаблону `templates/work/README.md`;
- пустой `files.txt`;
- запись в `docs/assignments.json`, если указать ссылку или срок.

После создания заполнить разделы «Что требовалось» и «Что сделано», записать
состав архива в `files.txt` и запустить `py scripts/sync.py`.

Кнопка «Подготовить к отправке» открывает папку работы и задание в Moodle
одновременно. Она активна для готовых работ, у которых есть ссылка в реестре.
