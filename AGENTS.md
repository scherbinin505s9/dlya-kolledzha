# Правила работы с репозиторием

## Учебные работы

Главное: работа должна выглядеть как работа студента, а не как сгенерированный текст.

- Делать строго по заданию. Не добавлять поля, функции, страницы, анимации и
  «улучшения», которых нет в методичке или на образце.
- Код — на базовом уровне, который проходят в колледже. Никаких библиотек,
  фреймворков, сборщиков и сложных приёмов, если их не требует задание.
- В коде не писать комментарии. Исключение — если преподаватель прямо требует
  комментарии в задании.
- Без эмодзи и смайликов в коде, тексте работы, README и сообщениях преподавателю.
- Без признаков ИИ: никаких служебных пометок, подписей, «сгенерировано» и
  рассуждений о том, как делалась работа. Только то, что просили сдать.
- Минимум файлов: только необходимые для сдачи.
- Простое и работающее важнее «красивого». Стиль — как в примерах из курса.
- Перед сдачей сверить результат с каждым пунктом задания и с образцом.
- Карточку работы вести по шаблону `templates/work/README.md`.
- Состав архива для Moodle записывать в `files.txt` в папке работы.
- Файлы из Moodle в CP1251 переводить в UTF-8 до правок.

## Перед отправкой

- Сверить работу с каждым пунктом задания и с образцом.
- Открыть страницы в браузере: ошибок нет, картинки и CSS загружаются.
- Проверить внешние ссылки: отвечают 200.
- Проверить `files.txt`: в архиве только нужные файлы.
- Заполнить карточку работы: статус, дата, оценка, имя архива.
- Собрать ZIP и сверить состав.
- После отправки перенести работу, обновить статус и запустить
  `py scripts/sync.py`.
- Если после отправки менялись файлы — собрать архив заново и отправить новую
  попытку.

## Репозиторий

- Всё содержимое — на русском, командами, готовыми к копированию.
- Пароли, токены и личные данные не коммитить.
- Выполненные работы класть в
  `Готово к отправлению/<Предмет>/<Название работы>/` с коротким `README.md`:
  предмет, что требовалось, что сделано, дата, статус.
- Отправлять задания в Moodle только по команде пользователя.
- После отправки переносить работу в
  `Отправленные задания/<Предмет>/<Название работы>/`.
- Перед коммитом запускать `py scripts/sync.py`: он обновляет списки работ и
  проверяет карточки и `files.txt`.

## Портал

- Курсы открывать только через https://portal.edu.asu.ru/, не через `lk.asu.ru`.
- Если для доступа к заданию нужна лекция — пройти её.
- Пройденные лекции записывать в `docs/lectures.md`: название и балл из журнала.
- Отправлять задания только после проверки и только по команде пользователя.
- В `README.md` работы фиксировать фактический статус из Moodle.
