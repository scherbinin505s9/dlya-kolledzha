# Управление браузером

## Когда применять

- посмотреть страницу, которая открывается только после входа (портал колледжа, ЛК, Moodle);
- найти или сверить информацию на сайте;
- проверить свою вёрстку на разных размерах экрана;
- заполнить форму, но **не отправлять** её без подтверждения пользователя.

## Что должно быть готово

MCP-сервер `playwright` подключён к OpenCode. Проверка:

```bash
opencode mcp list
```

Ожидается `✓ playwright connected`. Если сервера нет — установка в
[references/setup.md](references/setup.md).

## Рабочий цикл

1. **Открыть страницу** — `browser_navigate` с полным URL.
2. **Прочитать структуру** — `browser_snapshot`. Это дерево доступности:
   у каждого элемента есть `ref`, например `[ref=e42]`.
3. **Найти нужное** — `browser_find` по тексту или регулярному выражению.
   Дешевле, чем читать весь snapshot.
4. **Действие** — `browser_click`, `browser_type`, `browser_fill_form`,
   `browser_select_option`, `browser_press_key`.
5. **Проверить результат** — новый `browser_snapshot` или `browser_take_screenshot`.
6. **Закрыть** — `browser_close`, когда работа закончена.

`ref` устаревает после перехода на другую страницу. Перед каждым кликом
берите свежий snapshot, если что-то не находится.

## Прочитать список данных

Когда на странице таблица или список карточек, не листайте snapshot вручную —
выполните JS и верните JSON:

```js
() => {
  const out = [];
  document.querySelectorAll('a[href*="course/view.php"]').forEach(a => {
    const text = (a.textContent || '').trim().replace(/\s+/g, ' ');
    if (text) out.push(text);
  });
  return [...new Set(out)];
}
```

Вызов: `browser_evaluate` с этой функцией в поле `function`. Работает и для
таблиц: собирайте `tr` → `td.innerText`.

## Скриншоты

```
browser_take_screenshot({ scale: "css" })
```

Файл сохраняется в `.playwright-mcp/`. Если нужно посмотреть глазами —
прочитайте PNG инструментом `read`. Для длинной страницы добавьте
`fullPage: true`.

## Вход на сайты

1. Откройте страницу входа.
2. Скажите пользователю: «Войди в окне, которое открылось».
3. **Никогда** не просите пароль и не вводите его сами.
4. После входа сессия сохраняется в профиле браузера, и следующие страницы
   открываются уже авторизованными.

## Безопасность

- Не отправляйте формы, не оплачивайте, не удаляйте и не публикуйте без
  явного подтверждения.
- Не читайте и не пересказывайте личные данные, не относящиеся к задаче.
- Не обходите CAPTCHA, платные стены и ограничения доступа.
- Не вставляйте пароли, токены и cookie в ответы и файлы.
- После работы закрывайте браузер: `browser_close`.

## Частые проблемы

| Симптом | Причина | Решение |
|---|---|---|
| `Tool not found` | сервер не подключён | `opencode mcp list`, проверить конфиг |
| `Target page, context or browser has been closed` | браузер закрыли | `browser_navigate` заново |
| `strict mode violation` | селектор совпал с несколькими элементами | взять `ref` из свежего snapshot |
| Snapshot огромный | страница-каталог | `browser_find` или `browser_evaluate` |
| Снова просит пароль | профиль не сохраняется | проверить `--user-data-dir` |
| `ProcessSingleton` / профиль занят | тем же профилем пользуется другой Chrome | закрыть лишний экземпляр |
