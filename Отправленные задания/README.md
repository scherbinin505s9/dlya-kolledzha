## Правила

- в папку попадают только работы, которые действительно отправлены на проверку;
- имя папки = название задания на портале;
- в `README.md` работы: предмет, раздел курса, что требовалось, что сделано, дата и статус;
- пароли, токены и личные данные не добавляются.
