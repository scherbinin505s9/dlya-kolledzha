## Что требовалось

Для `text.htm`:

- создать `mystyle.css` и подключить его к странице;
- задать свои цвета фона и текста, чтобы текст хорошо читался;
- задать цвет заголовков H1 и H2, H2 выделить тёмным фоном и светлыми буквами,
  добавить внутренний отступ 5 px;
- создать класс `formula` для абзацев и отдельных слов: выравнивание по центру,
  жирный шрифт, курсив;
- создать класс `definition` для абзацев: рамка 1 px и внутренний отступ 10 px.

Для `cats.htm`:

- фон страницы `#FFEEEE`, шрифт Georgia или любой с засечками;
- для H1 и H2 — Arial, Helvetica или любой рубленый шрифт;
- для H1 — фоновый рисунок `images/cat.png` без повторения;
- для H2 — цвет `#800000`;
- класс `latin` — курсив и тёмно-красный цвет;
- всем абзацам — красная строка 30 px;
- класс `author` — курсив без абзацного отступа, для имён авторов цитат;
- класс `quote` — фон `#FEFEE2`, ширина 50%, отступы `0 30px 10px`, точечная
  рамка 1 px, внутренний отступ 10 px;
- имена авторов цитат — ссылки на страницы о них;
- ссылки внутри абзаца `author` — красные при наведении.

## Что сделано

- `text.htm` размечен: заголовки, абзацы, два блока определений и формулы
  с верхними и нижними индексами.
- `mystyle.css` подключён к `text.htm`.
- `CSS/cats.htm` размечен: абзацы, латинские названия, авторы и цитаты.
- `CSS/cats.css` подключён к `cats.htm`.
- Имена авторов ведут на статьи в Википедии.
