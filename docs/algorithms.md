## Сложность (что спросят на защите)

| Запись | Название | Пример |
|---|---|---|
| O(1) | константная | доступ по индексу `a[i]` |
| O(log n) | логарифмическая | бинарный поиск |
| O(n) | линейная | один проход по массиву |
| O(n log n) | линейно-логарифмическая | быстрая сортировка |
| O(n²) | квадратичная | вложенные циклы, пузырёк |
| O(2ⁿ) | экспоненциальная | перебор подмножеств |

Правило: константы и младшие слагаемые отбрасываются. `3n² + 5n + 7` → `O(n²)`.

## Базовые конструкции (Python)

```python
# условие
if x > 0:
    print("плюс")
elif x == 0:
    print("ноль")
else:
    print("минус")

# цикл по диапазону
for i in range(1, 11):
    print(i)

# цикл с условием
while n > 0:
    n //= 10

# функция
def average(numbers):
    if not numbers:
        return 0
    return sum(numbers) / len(numbers)
```

Те же конструкции в C#:

```csharp
if (x > 0) Console.WriteLine("плюс");
else if (x == 0) Console.WriteLine("ноль");
else Console.WriteLine("минус");

for (int i = 1; i <= 10; i++) Console.WriteLine(i);

static double Average(int[] numbers) =>
    numbers.Length == 0 ? 0 : numbers.Average();
```

| Структура | Когда использовать | Python | C# |

| массив / список | порядок, доступ по индексу | `list` | `List<T>`, `T[]` |

## Примеры

### Бинарный поиск

```python
def binary_search(a, target):
    low, high = 0, len(a) - 1
    while low <= high:
        mid = (low + high) // 2
        if a[mid] == target:
            return mid
        if a[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

Работает только на **отсортированном** массиве. Сложность `O(log n)`.

### Пузырьковая сортировка

```python
def bubble_sort(a):
    n = len(a)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        if not swapped:
            break
    return a
```

### НОД

```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a
```

### Системы счисления

```python
bin(42)          # '0b101010'
hex(255)         # '0xff'
int("101010", 2) # 42
int("ff", 16)    # 255
```

## Дискретная математика (ЕН.02)

- **Логика:** `and`, `or`, `not`; таблицы истинности; законы де Моргана.
- **Множества:** объединение, пересечение, разность; круги Эйлера.
- **Графы:** вершины, рёбра, степень, путь, кратчайший путь (Дейкстра).
- **Комбинаторика:** перестановки `n!`, сочетания `C(n,k)`.

Проверка формул — Python:

```python
from itertools import permutations, combinations
list(permutations([1, 2, 3]))      # 6 перестановок
list(combinations([1, 2, 3], 2))   # 3 сочетания
```

## Численные методы (ОП.10)

| Метод | Задача |
|---|---|
| метод половинного деления | корень уравнения `f(x)=0` |
| метод хорд / Ньютона | ускоренное уточнение корня |
| метод трапеций / Симпсона | определённый интеграл |
| метод Эйлера | решение дифференциального уравнения |

Типовая лабораторная на Python:

```python
def f(x):
    return x**3 - x - 2

a, b = 1, 2
for _ in range(20):
    mid = (a + b) / 2
    if f(a) * f(mid) < 0:
        b = mid
    else:
        a = mid
print((a + b) / 2)
```

## Как проверять свой код

```python
assert binary_search([1, 3, 5, 7], 5) == 2
assert binary_search([1, 3, 5, 7], 4) == -1
assert bubble_sort([3, 1, 2]) == [1, 2, 3]
assert gcd(12, 18) == 6
```

Граничные случаи, которые всегда проверяют: пустой массив, один элемент,
все элементы равны, уже отсортировано, отсортировано в обратном порядке,
отрицательные числа, очень большие числа.

## Частые ошибки на лабах

| Ошибка | Что не так |
|---|---|
| `IndexError` | выход за границы: цикл до `len(a)`, а не `len(a)-1` |
| бесконечный цикл | не меняется условие выхода |
| `None` в результате | забыт `return` |
| неверный ответ на границе | не проверены пустой массив и один элемент |
| `O(n²)` там, где хватит `O(n)` | вложенный поиск вместо словаря |
