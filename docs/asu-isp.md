## Что пригодится в этом семестре

1. **Python** — основной язык по «Основам алгоритмизации». Начинайте с
   [python.md](python.md), затем [algorithms.md](algorithms.md).
2. **SQL** — по «Основам проектирования баз данных» спрашивают `SELECT`,
   `JOIN`, `GROUP BY`, `HAVING`, создание таблиц и представлений.
3. **HTML/CSS/JS** — два курса сразу: «Основы веб-технологий» и
   «Проектирование интерфейсов». Один раздел [web-basics.md](web-basics.md)
   закрывает оба.
4. **Linux + PowerShell** — по «Операционным системам» лабораторные идут
   в обеих средах. Не пропускайте `chmod`, `ps`, `grep`, `ip`, `Get-Process`.
5. **Отчёты** — оформление проверяют почти в каждой лабораторной:
   [reports-gost.md](reports-gost.md).
