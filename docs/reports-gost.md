# Отчёты и документация (ОП.09)

Главное правило: **требования методички преподавателя важнее ГОСТа**. Ниже — стандартная
база, которую принимают в колледже.

## Структура отчёта

1. Титульный лист
2. Содержание
3. Введение (цель, задачи, актуальность)
4. Теоретическая часть
5. Практическая часть (ход работы, код, скриншоты)
6. Заключение (выводы по задачам)
7. Список использованных источников
8. Приложения (листинги, схемы)

## Титульный лист

Обычно содержит:

```
МИНИСТЕРСТВО НАУКИ И ВЫСШЕГО ОБРАЗОВАНИЯ РОССИЙСКОЙ ФЕДЕРАЦИИ
Алтайский государственный университет
Колледж АлтГУ

ОТЧЁТ
по лабораторной работе № 1
по дисциплине «Основы проектирования баз данных»

Выполнил: студент группы ИС-21
Иванов И. И.
Проверил: Петров П. П.

Барнаул, 2026
```

Точные поля и формулировки берите с образца на портале колледжа или у старосты.

## Оформление текста

| Параметр | Значение |
|---|---|
| Шрифт | Times New Roman, 14 пт |
| Межстрочный интервал | 1,5 |
| Абзацный отступ | 1,25 см |
| Выравнивание | по ширине |
| Поля | левое 30 мм, правое 15 мм, верхнее и нижнее 20 мм |
| Нумерация страниц | снизу по центру, титульный не нумеруется |
| Заголовки | полужирный, с новой страницы для разделов |

Заголовки: `1`, `1.1`, `1.1.1` — без точки в конце. Между номером и текстом — пробел.

## Рисунки и таблицы

Рисунок:

```
Рисунок 1 — Схема базы данных
```

Подпись **под** рисунком, по центру. В тексте — ссылка «см. рисунок 1».

Таблица:

```
Таблица 1 — Результаты тестирования
```

Подпись **над** таблицей, слева. Нумерация сквозная по всему документу.

## Формулы

В Word: `Alt+=` — редактор формул. Нумеруются в скобках справа:

```
E = mc²                                                         (1)
```

Ссылка в тексте: «по формуле (1)».

## Список источников

Порядок — по алфавиту или по мере упоминания (как требует методичка).

Книга:

```
Иванов, И. И. Базы данных : учебное пособие / И. И. Иванов. — Москва : Академия, 2024. — 256 с.
```

Сайт:

```
Документация PostgreSQL. — URL: https://www.postgresql.org/docs/ (дата обращения: 15.11.2026).
```

В тексте ссылка: `[1]`, `[2, с. 45]`.

## Word: ускоряем оформление

1. **Стили.** Настроить «Обычный» (Times New Roman 14, интервал 1,5, отступ 1,25) и
   «Заголовок 1/2» — всё применится разом.
2. **Многоуровневый список** для заголовков → автонумерация `1`, `1.1`.
3. **Содержание** вставляется автоматически: Ссылки → Оглавление. После правок — «Обновить».
4. **Названия** (подписи): Ссылки → Вставить название. Тогда нумерация рисунков
   пересчитывается сама.
5. **Разрыв страницы** (`Ctrl+Enter`) для новых разделов, а не пустые абзацы.
6. **Неразрывный пробел** (`Ctrl+Shift+Space`) в «рисунок 1», «таблица 2», «т. е.».
7. **Проверка:** Рецензирование → Орфография; файл → Проверка документа на скрытые данные.

## Типичные замечания преподавателей

| Замечание | Как исправить |
|---|---|
| «Нет ссылок на рисунки в тексте» | перед каждым рисунком — «на рисунке 1 показано…» |
| «Скриншот мелкий и нечитаемый» | обрезать лишнее, увеличить масштаб интерфейса до снимка |
| «Код без подсветки и нумерации» | вставить как моноширинный текст или скриншот с номерами строк |
| «Выводы не по задачам» | в заключении — по пункту на каждую задачу из введения |
| «Источники старше 5 лет» | добавить актуальную документацию и учебники последних лет |
| «Содержание не совпадает» | обновить автособираемое оглавление после правок |
| «Разные шрифты» | применять стили, а не менять шрифт вручную |
| «Поля не по ГОСТ» | Макет → Поля → Настраиваемые |
