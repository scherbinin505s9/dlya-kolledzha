# Linux: база

Минимум, который нужен на любой лабораторной машине.

## Где я и что вокруг

```bash
pwd                 # текущая папка
ls -la              # файлы, включая скрытые
cd /путь            # перейти
cd ..               # на уровень выше
cd ~                # в домашнюю папку
cat /etc/os-release # что за дистрибутив
uname -a            # ядро и архитектура
df -h               # свободное место
free -h             # оперативная память
```

## Файлы и папки

```bash
mkdir -p проекты/лаб1      # создать папку со всеми родителями
touch notes.md             # создать пустой файл
cp файл копия              # копировать
cp -r папка папка2         # копировать папку
mv файл новое_имя          # переименовать / переместить
rm файл                    # удалить файл
rm -rf папка               # удалить папку (осторожно, без корзины!)
ln -s /цель ссылка         # символическая ссылка
```

## Поиск

```bash
find . -name "*.py"              # найти файлы по имени
grep -rn "текст" .               # найти текст во всех файлах
grep -i "текст" файл             # без учёта регистра
which python3                    # где лежит программа
history | grep apt               # что я уже вводил
```

## Права и sudo

```bash
chmod +x script.sh          # сделать файл исполняемым
chmod 644 файл              # владелец читает/пишет, остальные читают
chmod 755 файл              # владелец всё, остальные читают/выполняют
ls -l                       # посмотреть права
sudo команда                # выполнить от администратора
sudo -s                     # открыть root-оболочку (выход: exit)
sudo -u пользователь команда
```

Расшифровка `ls -l`: `-rwxr-xr--` = тип, права владельца, группы, остальных.
`r` — чтение, `w` — запись, `x` — выполнение.

> `sudo` просит ваш пароль, а не root. Пароль при вводе не отображается — это нормально.

## Пакеты

```bash
# Debian / Ubuntu / Mint
sudo apt update && sudo apt upgrade -y
sudo apt install -y пакет
sudo apt remove -y пакет
apt search пакет

# Fedora
sudo dnf install -y пакет
sudo dnf remove -y пакет

# Arch / Manjaro
sudo pacman -Syu
sudo pacman -S пакет

# openSUSE
sudo zypper install пакет

# Alpine
sudo apk add пакет
```

Если `apt` пишет `Could not get lock /var/lib/dpkg/lock-frontend` — другой процесс уже обновляется. Дождитесь его или:

```bash
sudo killall apt apt-get
sudo rm /var/lib/apt/lists/lock
sudo dpkg --configure -a
```

## Процессы и порты

```bash
ps aux | grep python      # найти процесс
top                       # живой список процессов (выход: q)
htop                      # то же, но удобнее
kill 1234                 # завершить процесс по PID
kill -9 1234              # принудительно
ss -tulpn                 # какие порты заняты
lsof -i :3000             # кто занял порт 3000
```

## Сеть

```bash
ip a                       # IP-адреса
ping -c 4 ya.ru            # доступность хоста
curl -I https://ya.ru      # HTTP-заголовки
wget https://url/файл      # скачать файл
scp файл user@host:/путь   # скопировать на другую машину
```

## Архивы

```bash
tar -xzf архив.tar.gz       # распаковать
tar -czf архив.tar.gz папка # упаковать
unzip архив.zip
zip -r архив.zip папка
```

## Полезные мелочи

```bash
clear            # очистить экран (или Ctrl+L)
Ctrl+C           # прервать команду
Ctrl+D           # выйти из оболочки / завершить ввод
Ctrl+R           # поиск по истории команд
!!               # повторить предыдущую команду
sudo !!          # повторить предыдущую с sudo
command | less   # длинный вывод постранично (выход: q)
команда > файл   # записать вывод в файл
команда >> файл  # дописать в конец
```

`>` **перезаписывает** файл, `>>` **дописывает**. Это самая частая причина потерянных данных.
