# Архитектура аппаратных средств (ОП.02)

## Из чего состоит компьютер

| Устройство | Что важно знать |
|---|---|
| Процессор (CPU) | ядра, потоки, тактовая частота, кэш L1/L2/L3, TDP |
| Оперативная память (RAM) | объём, тип DDR4/DDR5, частота, каналы |
| Накопитель | SSD (SATA/NVMe) или HDD, объём, скорость |
| Видеокарта (GPU) | объём видеопамяти, дискретная или встроенная |
| Материнская плата | сокет, чипсет, слоты, форм-фактор |
| Блок питания | мощность в ваттах, 80 PLUS |
| Периферия | монитор, клавиатура, мышь, сетевой адаптер |

**Принцип фон Неймана:** память хранит и данные, и команды; процессор выполняет команды
последовательно; обмен идёт через шины (шина данных, адреса, управления).

**Узкое место** (bottleneck) — самый медленный компонент. В учебных ПК чаще всего это HDD
или нехватка RAM, а не процессор.

## Единицы измерения

```
1 байт = 8 бит
1 КБ = 1024 байта
1 МБ = 1024 КБ
1 ГБ = 1024 МБ
1 ТБ = 1024 ГБ
```

Производители дисков считают по 1000, поэтому диск «на 500 ГБ» в системе показывает ~465 ГБ.
Это нормально, а не обман.

Скорости: пропускная способность — биты в секунду (Мбит/с), объём — байты (МБ).
`100 Мбит/с ≈ 12,5 МБ/с`.

## Системы счисления

| DEC | BIN | HEX |
|---|---|---|
| 0 | 0000 | 0 |
| 1 | 0001 | 1 |
| 2 | 0010 | 2 |
| 5 | 0101 | 5 |
| 7 | 0111 | 7 |
| 10 | 1010 | A |
| 15 | 1111 | F |
| 255 | 11111111 | FF |

Перевод:

```python
bin(42)            # '0b101010'
hex(42)            # '0x2a'
int('101010', 2)   # 42
int('2a', 16)      # 42
```

Вручную из десятичной в двоичную — деление на 2 с записью остатков снизу вверх.
Из двоичной в шестнадцатеричную — разбить на тетрады справа: `1010 1010` → `AA`.

## Представление данных

- **Текст:** ASCII (128 символов), Unicode/UTF-8 (все языки). Русская `А` в UTF-8 — 2 байта,
  в Windows-1251 — 1 байт. Отсюда «кракозябры» при неверной кодировке.
- **Цвет:** RGB, каждый канал 0–255, `#FF5733` = `rgb(255, 87, 51)`.
- **Звук:** частота дискретизации (Гц) × разрядность (бит) × каналы.
- **Изображение:** разрешение × глубина цвета. `1920×1080` при 24 бит ≈ 6 МБ без сжатия.

## Логические элементы

| Элемент | Операция | Обозначение |
|---|---|---|
| И | конъюнкция | `AND`, `&`, `∧` |
| ИЛИ | дизъюнкция | `OR`, `\|`, `∨` |
| НЕ | инверсия | `NOT`, `!`, `¬` |
| Исключающее ИЛИ | XOR | `^`, `⊕` |

Таблицы истинности и законы де Моргана: `¬(A ∧ B) = ¬A ∨ ¬B`, `¬(A ∨ B) = ¬A ∧ ¬B`.

## Посмотреть характеристики

Linux:

```bash
lscpu                     # процессор
free -h                   # память
lsblk                     # диски и разделы
df -h                     # занятое место
lspci                     # устройства PCI
sudo dmidecode -t memory  # модули RAM
sudo smartctl -a /dev/sda # здоровье диска (пакет smartmontools)
```

Windows:

```powershell
systeminfo
Get-CimInstance Win32_Processor | Select Name, NumberOfCores, MaxClockSpeed
Get-CimInstance Win32_PhysicalMemory | Select Capacity, Speed
Get-PSDrive
```

## Виртуализация

Для лабораторных по ОС часто нужна виртуальная машина:

- **VirtualBox** — бесплатно, `winget install Oracle.VirtualBox`;
- **VMware Workstation Player** — бесплатно для личного использования;
- **Hyper-V** — встроен в Windows Pro, `wsl --install` тоже использует его.

Минимальные параметры ВМ для Ubuntu Server: 2 ядра, 2–4 ГБ RAM, 20 ГБ диска.
Для графической оболочки — 4 ГБ RAM и 25 ГБ диска.

## Что спросят на защите

- Чем отличаются ядро и поток, что такое гиперпоточность.
- Зачем кэш и почему он быстрее RAM.
- Чем SSD отличается от HDD и почему NVMe быстрее SATA.
- Что такое разрядность и адресное пространство.
- Как перевести число из десятичной в двоичную и обратно.
- Что делает северный и южный мост (или чипсет в современных платах).

## Частые ошибки

| Ошибка | Как правильно |
|---|---|
| «1 КБ = 1000 байт» | в информатике 1024, у производителей дисков 1000 |
| путать биты и байты | `Мбит/с` — скорость сети, `МБ` — размер файла |
| «частота = производительность» | важны ядра, кэш, IPC, охлаждение |
| ставить мощный CPU на HDD | сначала устранить узкое место |
| `dmidecode` без sudo | нужны права root |
| смотреть объём диска в `df` без `-h` | непонятные килобайты |
