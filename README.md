# для колледжа

Учебная база по специальности **09.02.07 «Информационные системы и программирование»**
(колледж АлтГУ): шпаргалки, готовые к отправке и сданные работы, скрипты настройки.

## Запуск

Нужен только Node.js LTS с [nodejs.org](https://nodejs.org/).

Установка один раз:

```bash
npm install -g @opencode/cli
```

Дальше — из папки репозитория:

```bash
cd dlya-kolledzha
opencode
```

Репозитория ещё нет:

```bash
git clone https://github.com/scherbinin505s9/dlya-kolledzha.git
```
